# KOISU - YouTube Video & Audio Converter

Локальное веб-приложение на Next.js, yt-dlp и FFmpeg для скачивания YouTube
видео, аудио и отдельных моментов.

## Возможности

- Видео: MP4, MKV, WebM, выбор доступного качества до 4K.
- Аудио: MP3 до 320 kbps, M4A, FLAC, WAV и AAC.
- Моменты: поля начала и конца в формате `mm:ss` или `hh:mm:ss`.
- Прогресс: скорость, размер, оставшееся время и статус обработки.
- Cookies: поддержка `cookies.txt` для роликов с возрастным ограничением.
- История: быстрый повторный доступ к готовым файлам текущих запусков.

## Запуск

### Windows

Запустите `run.bat`.

### Через терминал

```bash
npm install
npm run dev
```

Откройте в браузере `http://localhost:3000`.

## Как скачать отрезок

1. Вставьте ссылку YouTube.
2. Выберите видео или аудио, качество и формат.
3. В блоке `Скачать момент` укажите начало и конец, например `0:35` и `1:20`.
4. Нажмите `Скачать`.

Если поля начала и конца оставить пустыми, KOISU скачает ролик целиком.
